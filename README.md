# 📊 Universal CSV Analyzer Web App

An interactive web application built with Streamlit that analyzes ANY CSV file instantly!

## 📌 Features
- 📂 Upload any CSV file
- 📊 Auto-detects columns and data types
- 📈 Shows basic statistics
- 📉 Generates bar chart and box plot
- ⬇️ Download Excel report with one click

## 🛠️ Tools Used
- Python 3.12
- Pandas
- Matplotlib
- Streamlit
- OpenPyXL

## 🚀 How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas matplotlib streamlit openpyxl`
3. Run: `streamlit run app.py`
4. Upload any CSV file and get instant analysis!
